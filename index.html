JavaScript library for WhatsApp Web

A Baileys build for modern WhatsApp automation.

Lynox is a community-maintained JavaScript library based on Baileys. Connect a WhatsApp Web session, handle messages, media, groups, and newsletters with a familiar Node.js API.

Quick start

Clone the library, install dependencies, and connect a session from your Node.js project.

  1. Use Node.js 22 or newer.
  2. Install the repository locally.
  3. Connect with QR or pairing code.
  4. Listen for messages and events.
# clone the library
git clone https://github.com/lyn0x-dev/baileys-by-lynox.git
cd baileys-by-lynox
npm install

// index.js
const makeWASocket = require('./lib')
const { useMultiFileAuthState } = require('./lib/Utils')

const start = async () => {
  const { state, saveCreds } =
    await useMultiFileAuthState('auth')

  const sock = makeWASocket({ auth: state })

  sock.ev.on('creds.update', saveCreds)
  sock.ev.on('messages.upsert', ({ messages }) => {
    console.log(messages)
  })
}

start()
